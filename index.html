Jarvis

개인용 비서 프로그램 · Personal assistant for a single user

Jarvis는 개발자 한 사람이 자신의 Mac에서만 쓰는 개인 비서 프로그램입니다. 매일 아침 자신의 Google 캘린더 일정과 Google Tasks 할 일을 읽어 요약하고, 자신의 카카오톡("나에게 보내기")으로 알려 줍니다. 공개 서비스가 아니며 다른 사람은 가입하거나 사용할 수 없습니다.

Jarvis is a personal assistant that runs only on its developer's own Mac. It reads the developer's own Google Calendar events and Google Tasks (read-only) to send them a daily summary. It is not a public service.
